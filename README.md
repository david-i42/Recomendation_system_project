# Recomendation_system_project
Рекомендательная система, предлагающая пользователям социальной сети посты, на основе их предпочтений

Использует информацию о признаках пользователей (пол, возраст, итд), тематики и особенности текста постов, склонность конкретного пользователя ставить like постам в зависимости от их тематики, популярность самих постов.
