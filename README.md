# Recomendation_system_project

Рекомендательная система, предлагающая пользователям социальной сети посты, на основе их предпочтений

Одно из направлений развития социальной сети - улучшение пользовательского опыта. С этой целью необходимо сформулировать решение, которое бы подбирало контент (посты), максимально подходящие под интересы каждого из пользователей. 

Целью данного проекта является создание пайплайна и прототипа ml-сервиса, с backend. Этот сервис должен уметь принимать id конкретного пользователя через веб-запрос, и на его основе делать предсказание - список id постов, которым пользователь, скорее всего, поставит лайк.



Стек:
Python 3.8

	Библиотеки:
		pandas и numpy - работа с датафреймами и векторами
		matplotlib и seaborn - визуализация данных
		sqlalchemy - работа с БД из python приложения
		catboost - модель для создания прогнозов
		torch - поддержка GPU моделью, работа с тензорами
		sklearn - обучение и проверка качества моделей, анализа tf-idf, снижение размерности PCA, кластеризации методом K-means, нормализация
		transformers - работа с текстом через DistillBertModel
		fastapi - создание API
		uvicorn - работа с сервером
	


Для достижения цели я провёл разведочный анализ данных и создал на его основе пайплайн, который извлекает информацию о постах и пользователях, генерирует на их основе набор данных под работу модели. 
Подготовил модель, которая  на основе признаков выдаёт рекомендации под id конкретного пользователя. Для поддержки работы сервиса сделал доступ к данным через ORM (SQLAlchemy), написал веб-запросы, привязал к эндпоинтам (FastAPI).

Сделанный мной пайплайн работает с признаками пользователя (пол, возраст), поста (тематика), агрегированными данными по количеству лайков и просмотров, извлекает признаки из текста поста. На основе этого, он рекомендует 5 постов, качество прогноза составляет 0,6 по метрике hitrate@5, то есть в 60% случаев в 5 рекомендуемых постах выдаётся тот, который понравится (проверка на основе тестовой выборки).
